# Style directions

Choose from the product, audience, selected concept and supplied identity. These directions are menus; colors, fonts, layout and sequence are not templates.

| Direction | Surface/type | Motion vocabulary | Useful context |
| --- | --- | --- | --- |
| Cinematic dark | Dark layered depth, strong clean type | Motivated reveal, lens foreground, depth | Creative tools, entertainment |
| Poster color-block | Brand fields, heavy display type | Edge collisions, block wipes, cropped words | Events, consumer launches |
| Editorial light | White/cream, restrained rules, serif/grotesk contrast | Clear reveals, calm repositioning | SaaS, productivity |
| Paper and print | Paper, collage, stamps; handwriting accents | Cutouts land, annotations draw | Education, community |
| Retro/analog | Faded ink/grain, era-specific lettering | Controlled glitch, rough zoom, freeze | Nostalgia, music |
| Brutalist mono | Hard grid, mono/condensed type | Cuts, shifting blocks, cursor rhythm | Developer tools |
| Pastel playful | Rounded forms, layered pastels | Elastic action and gentle overshoot | Friendly consumer products |
| Luxury dark | Restrained dark/material accents, elegant type | Slow reveal, sweeping light, depth | Premium products |
| Flat pop with photos | Photo cutouts, brand fields, bold rounded type | Cutout arrivals, stickers, triggered field changes | Consumer campaigns |
| Grainy gradient | Saturated layered shapes, fine grain | Shape opening, parallax, camera through forms | Tech, creative launches |

Derive each palette color from a source or explain the derived choice. Choose available local font files before making text-fit claims. UI typography follows the actual product when depicting its interface. A distinctive display font is optional, not a prohibition on the user's brand typeface.

Object render families: flat vector, line drawing, paper cutout, clay, glossy solid, translucent glass, isometric, photoreal and neon wire. Select for meaning and asset consistency. Do not introduce glass/glow automatically because the starter uses it.

For complex references, separate observed properties from inferred technique. “Paper & print” does not require duplicating another video's unique opening or composition.
