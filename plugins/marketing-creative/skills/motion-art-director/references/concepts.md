# Concept structures

Use these to develop different arguments and visual mechanisms. None mandates a scene order or guarantees results.

| Structure | Mechanism / suitable material |
| --- | --- |
| One continuous shot | Follow a spatial/product transformation with a coherent point of view |
| Pure typography | Words carry the argument; rhythm and emphasis reveal meaning |
| Problem → gone | Show a recognizable obstacle removed by a visible mechanism |
| Before/after | Fairly compare states using supported conditions |
| Journey inside UI | Follow the useful task through product-grounded components |
| Product macro | Reveal material, detail or craft; strong physical assets |
| Object metaphor | Make a system tangible; clearly distinguish metaphor from evidence |
| Living number | Reveal a supported number through a counting/transforming object |
| One feature fully demonstrated | Input → interaction → useful result |
| Question → answer | Answer a buyer's real question; editorial questions are labeled |
| Rhythmic collage | Assemble a world from related assets with meaningful rhythmic relations |
| Logo as stage | Brand shape structures reveals and spatial movement |
| Object relay | One object carries a process or handoff between participants |
| Brand system showcase | Demonstrate the identity through applications and coherent motion |
| Claim → how → result | Prove each claim immediately through its actual mechanism |
| Living UI ecosystem | Show roles/integrations completing a coherent workflow |
| Flat pop with photos | Person/product cutouts and brand fields respond to action |
| Through gradient shapes | Shapes guide attention and reveal product meaning |
| Product tour with claims | Alternate useful interactions with concise contextual claims |

Distinguish concept from style: a task demonstration can be editorial light or flat pop; a color swap does not create a new persuasive idea. Choose fewer concepts when a direction is already selected. Avoid copying an example's search box, three feature cards or logo ending unless the selected idea calls for them.

Example applications for a fictional collaboration tool:
- Object relay: a document moves from draft to review to completion.
- Barrier reversal: existing work survives migration; show the actual supported import.
- One-feature demo: one assignment becomes a completed handoff.

The examples are hypotheses, not product claims. Real campaigns need the brief's evidence and available assets.
