# Runnable construction examples

Initialize a project with the [project tool](../../motion-video-producer/scripts/project.py), then use the [composer](../../motion-composer/scripts/compose.mjs). The eight-second sample contains five small beats, one for each primitive. It is an architectural specimen, not a recommended five-beat ad.

| Primitive | What the code demonstrates | What to replace for production |
| --- | --- | --- |
| type | Claim hierarchy, explicit entrance, landscape/portrait line measure | Actual copy, brand type, pacing and visual argument |
| ui-tour | Panel, pointer-triggered state change and useful result | Product-grounded UI/captures and supported task |
| counter | Seek-safe numeric reveal through a supported value | Verified number, unit, source and narration anchor |
| collage | Related cutouts share a world; staggered entry and a focus shift | Actual sourced imagery and narrative connection |
| stage | Local character/prop action and camera framing | Appropriate characters, environment and causal action |

The sample's labels explicitly identify fictional demonstration content. It carries no customer claims, real brand identity, upstream gallery media or paid assets. To isolate one primitive, replace the beat array with a single beat covering the runtime; a specific requested example need not include all modes.

Compare ratios at the same times. Landscape uses side-by-side copy/visual; portrait stacks them; square reduces spacing and uses a compact panel; 4:5 retains more vertical breathing room. A production generator should customize beyond these basic layouts.

Review prompts: Does the first frame communicate? Does each action change understanding? Is the important UI/result readable? Does a counter have evidence? Does the transition preserve attention? Can the CTA be understood without sound? Compare actual frames, not just code.
