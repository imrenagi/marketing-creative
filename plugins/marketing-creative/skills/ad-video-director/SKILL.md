# Ad Video Director

Develop the selected concept into a video someone can shoot or animate. Preserve the strategic objective, evidence, chosen idea and authorization already supplied.

## Start from the selected idea

Read `MARKETING_BRIEF.md`, `CREATIVE_BRIEF.md`, assets and constraints. A supplied equivalent is sufficient; do not require document creation for a small script request. For a fresh full-campaign request, use [marketing-brief](../marketing-brief/SKILL.md) then [creative-ideation](../creative-ideation/SKILL.md). If the user already chose an idea, develop it directly. Route strategic changes or requests for alternative concepts back to those skills instead of silently replacing the direction.

## Write the executable version

Read [timing-and-copy.md](references/timing-and-copy.md), [formats-and-timelines.md](references/formats-and-timelines.md) and [handoff.md](references/handoff.md). Cover the entire requested runtime with each interval's persuasive job, exact dialogue or intentional silence, exact overlay, shot/action, evidence asset and meaningful edit/audio cue. Continuous shots can span several intervals; a one-second breakdown does not require cuts every second.

Write idiomatically in the requested language. Time a read-through; words-per-minute is only a draft estimate and does not transfer reliably across languages. Give UI interactions, numbers, proof and CTA enough comprehension time. Avoid unrelated long narration, detailed UI and long overlays competing simultaneously.

Use only verified prices, offers, testimonials and product behavior. Keep a claim ledger: exact claim → evidence → allowed wording → asset → status. A demonstration proves the shown task under shown conditions, not universal results.

## Plan every requested output

Read [placement profiles](../motion-video-producer/references/placements.md). Produce a shared argument with explicit adaptations for 16:9, 9:16, 4:5 and/or 1:1 as requested. Distinguish canvas ratio, placement safe area, resolution, duration and sound assumptions. For short cuts, preserve the shortest complete argument or explain the changed job; never simply accelerate the long version.

## Review and hand off

Check relevance, hook payoff, attribution, proof, readability, continuity, action/destination and producibility. Use [testing.md](references/testing.md) for focused variants and measurement. Reference analysis and research resources remain available when evidence would change a decision.

Deliver exact script and production notes. For authorized production, create `script.json` with stable segment IDs using the [project contract](../motion-video-producer/references/project-contract.md), alongside the human-readable script. Early seconds are provisional until actual audio is aligned. Pass the briefs, selected concept, script, assets and placement requirements to [motion-video-producer](../motion-video-producer/SKILL.md).

Planning alone does not authorize rendering, publishing, ad spend or outreach. Do not claim an MP4 exists when only a script was produced.
